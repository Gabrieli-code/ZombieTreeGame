# Sobrevivência Zumbi

## Descrição

O projeto Sobrevivência Zumbi foi desenvolvido para a disciplina de Algoritmo e Estrutura de Dados com o objetivo de demonstrar a aplicação da estrutura Árvore Binária de Decisão em um sistema interativo.

O jogo apresenta perguntas ao usuário, que deve responder utilizando as opções "Sim" ou "Não". Cada resposta conduz a um caminho diferente da árvore até alcançar um resultado final.

## Estrutura de Dados Utilizada

Árvore Binária de Decisão.

Cada nó da árvore representa uma pergunta ou resultado. Os ramos representam as respostas "Sim" e "Não".

## Como Executar

1. Baixe ou clone o projeto.
2. Abra a pasta no Visual Studio Code.
3. Execute o arquivo `index.html` em um navegador.

## Estrutura da Árvore

Lutar?

├── Não
│   └── Correr?
│       ├── Não → O zumbi alcançou você
│       └── Sim → Você conseguiu escapar

└── Sim
└── Tem arma?
├── Não → Você foi derrotado
└── Sim → Você sobreviveu

## Objetivo Acadêmico

Demonstrar o funcionamento de uma Árvore Binária de Decisão e sua aplicação em sistemas de tomada de decisão.
